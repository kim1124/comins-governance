## Official guidance reviewed

- OpenAI [GPT-5.6 model guidance](https://developers.openai.com/api/docs/guides/latest-model):
  keep prompts lean, state each instruction once, keep approval and tool text
  compact, and validate changes on representative tasks.
- OpenAI [AGENTS.md discovery](https://learn.chatgpt.com/docs/agent-configuration/agents-md):
  Codex concatenates the applicable root-to-working-directory instruction
  chain. The default 32 KiB limit is a discovery ceiling, not a target size.
- Anthropic [Claude Code memory](https://code.claude.com/docs/en/memory) and
  [best practices](https://code.claude.com/docs/en/best-practices): keep the
  always-loaded file concise and route path-specific or repeatable workflows
  to scoped rules and skills.
- GitHub [Copilot custom instructions](https://docs.github.com/en/copilot/how-tos/copilot-on-github/customize-copilot/add-custom-instructions/add-repository-instructions)
  and [effective instruction guidance](https://docs.github.com/en/copilot/concepts/prompting/response-customization#writing-effective-custom-instructions):
  prefer short, independent, generally applicable rules and path-specific
  instructions without conflicts.
- Google [Gemini CLI context files](https://geminicli.com/docs/cli/gemini-md/)
  and [skill practices](https://geminicli.com/docs/cli/skills-best-practices/):
  keep root context small, discover path context when relevant, and load
  specialized workflows on demand.

These sources converge on progressive disclosure and single ownership. None
defines a universal recommended byte count, so Comins retains measured local
budgets instead of treating a provider limit or line count as a quality goal.

## Decisions

1. Keep `AGENTS.md` as a small automatic router and
   `COMINS_CONTRACT.md` as the only common execution-policy owner.
2. Load the Contract once for a change run; inspection-only work loads it only
   when a Contract stage is relevant.
3. Keep license, sensitive-data, and release mechanics in triggered policy
   files rather than duplicating them in the Contract or module block.
4. Preserve byte guardrails and measure automatic guidance, common policy, and
   triggered policy separately.
5. Preserve the mutable `main` link for separately reviewed adoption, but stop
   when the linked Contract heading and managed block version differ.
6. Keep request authorization compact: read-only requests do not authorize
   edits, while change requests authorize in-scope local edits and affected
   non-destructive checks.
